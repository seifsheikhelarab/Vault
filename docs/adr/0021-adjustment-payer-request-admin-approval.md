# Payer-requested, admin-approved Adjustments

The original Expense payer creates an Adjustment request with a mandatory reason. A Group owner or admin approves or rejects the request. An approved Adjustment becomes immutable and participates in derived balances; a rejected request has no financial effect.

The alternative — applying payer-created corrections immediately — makes a correction effective before another responsible person has reviewed a change to shared liabilities. Allowing admins to create corrections directly weakens ownership and makes it harder to distinguish a payer's correction from an administrative rewrite.

The trade-off is a pending workflow and an approval surface for the Group. That cost is justified because Adjustments can change who owes what while preserving an original financial record, so the change needs explicit accountability.
