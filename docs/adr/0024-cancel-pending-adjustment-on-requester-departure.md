# Cancel pending Adjustments when the requester leaves

A pending Adjustment is automatically cancelled when its requester loses active Membership in the Group. The cancellation remains visible in audit history, has no financial effect, and leaves the original Expense authoritative. A stale request cannot later be approved after its accountable payer has departed.

The alternatives — keeping the request pending for another admin to approve or transferring it to another administrator — allow a correction to become financially effective without the original payer remaining accountable. That weakens the request/review model and makes the request's original context harder to explain.

The trade-off is that a new active correction request may be needed if the departure was legitimate but the correction remains necessary. This is preferable to silently transferring financial authorship.
